## 🧩 Featured Projects

### 🗺️ RepoMap

An open-source developer tool that analyzes a codebase and turns its structure and relationships into understandable architectural maps.

```txt
→ Analyzes project structure
→ Extracts relationships and dependencies
→ Generates architectural visualizations
→ Helps developers understand unfamiliar codebases
```

**Goal:** Make understanding a large codebase significantly easier.

---

### ❄️ SnowID / SnowIDv2

A Rust library for generating unique distributed IDs for modern backend systems.

```txt
→ High-performance ID generation
→ Distributed-safe design
→ Rust implementation
→ Built for backend and production systems
```

Published as an open-source Rust package and designed to be reusable by other developers.

### 🔎 AI Search & Discovery

I'm experimenting with systems that help businesses and open-source projects become more discoverable through **AI search and recommendation systems**.

Instead of optimizing only for traditional search engines, the idea is to understand:

```txt

    ↓

```

The broader goal is to understand **how AI systems discover, evaluate, and recommend software and businesses**.
